# R14 研究资格和筛选修复

实现范围：G01、G02、I01、I02、I03；B06中的筛选输入。

- 统一 `research_gate.require_legacy_research_eligibility()`：旧表缺逐行PIT/来源合同，默认拒绝生成和读取旧推荐。仅 `APP_ENV=test` 且 `MARKET_DATA_MODE=mock` 可执行测试演示；生产mock也拒绝。新门禁同时供回测工作包调用。
- 推荐全部路由（含历史和单个标的）依赖门禁；服务写入/读取也独立检查，不能绕过HTTP直接调用。拒绝返回409，不创建run。
- 演示输出含来源等级、模型版本、时间、不可交易和未验证标识；`confidence_level=null`，旧线性值另名uncalibrated_score，明确不是概率；高等级也不再产生execute建议。
- 真实旧筛选要求存在有效非ST且未停用的StockMaster，行情不未来且不超过300秒；有20条非未来、近7日内更新、数值有效日线。未知或缺资格均不进入候选；读取历史候选时再验证当前资格。此为保守观察筛选，不将其称为PIT投资推荐。
- 筛选/预设使用extra=forbid的类型合同；负数/非有限值、反向上下界、未知市值/财务/行业键全部422。现有表没有这些可信字段，宁可明确拒绝，也不伪装已完成相应选股需求。
- 弱量统一输出weak_volume；风险函数兼容已有weak_volume_support且不重复计分。
- 所有期货研究候选在缺权益/头寸/压力模型时阻断，不再用保证金比例高低决定低风险。

验证：使用内存SQLite，`test_r14_research.py`、module2、legacy gates、multiasset合计57 passed；补充正向筛选与独立资格fixture后，本分支全量218 passed。未调用真实行情、未连接账户、未做交易。

限制：未实现真实PIT数据迁移、健康财务/流通市值字段和行业成分资格。因此G01采取安全阻断而非宣布真实推荐已可用，I01对应业务能力仍需可信数据字段落地；应在总状态表标注“未知筛选不再静默接受；业务数据能力待补”。
