## 使用入口

`/research` 为新研究终端：多市场切换、研究周期、来源覆盖与失败状态、行业/关键字/排序、观察池表格、候选资格、标的缓存核验、证据/反证/失效条件笔记。笔记实际写入同一应用数据库，支持新增、编辑、删除与重载恢复；不是仅存在React状态里的演示。

## 本机升级

使用Python3.11/3.12与Node22，执行原Windows bootstrap/start脚本。默认数据库`data/aistock.local.sqlite3`；先备份已有数据库。新笔记与幂等表自动新建，既有表不兼容会明确拒启动，不自动丢数据。

管理操作需本机环境`AISTOCK_ADMIN_TOKEN`（至少32字符），通过授权本地API客户端的`X-Aistock-Admin-Token`发送，和行情ingest token不同；浏览器研究工作台不索要这些秘密。笔记默认允许`http://localhost:3000`及`http://127.0.0.1:3000`来源，可用`AISTOCK_WEB_ORIGIN`改为实际本机来源。Compose显式允许内部api hostname，不盲信任任意forwarded头。
