# R14 回测修复

工作包：G04、B01、B02、B03、B04、B06（回测输入）；并接入G01共享研究资格门禁。

- API和直接服务调用复用BacktestParameters。负数、非有限数、不合理费率、倒置/未来日期、未知参数拒绝；API返回422，创建任务前验证。
- 当日完整收盘数据仅形成下一根bar的开盘待执行指令；最后一根不新开仓。买卖时间记录为开盘09:30/终点清仓15:00。
- 使用实际执行价（统一4位精度）计算成交金额；买入佣金计入回合成本，卖出佣金和印花税完整扣除。
- 期末平仓先于末点权益保存，现金、曲线末点、收益一致。平均持仓期按每回合的观测间隔累计。
- Sortino不足两个下行观测或零下行离散度返回null并附状态；Sharpe和Calmar零分母亦返回null。报告使用严格JSON，携带来源/未验证/禁止交易合同。
- legacy实时库没有PIT资格，所有回测读写入口默认409；仅显式APP_ENV=test且MARKET_DATA_MODE=mock可进行离线夹具验证。共用门禁由research工作包提供。

验证：新回归包含费用校验、直接服务绕过、无末bar新开仓、下一开盘成交、完整回合成本与净亏胜率、强平末点一致、持仓期、Sortino缺样本和real门禁。连同原module3/module6验收共22 passed（后续新增字段后再复跑）。

限制：这是日线原型执行规则，不声称已具备交易日历、涨跌停/停牌/成交量容量/逐笔撮合或样本外收益能力。真实回测仍被共享门禁阻断。历史旧报告不会自动重算；不能将旧数值迁移为已修复结果。
