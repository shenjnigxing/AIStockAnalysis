# AIStock V2 — 数据可信度优先的第一轮实现

日期：2026-10-21
分支：`feat/aistock-research-v2`
发布状态：**Research Preview / 不能生成真实股票推荐**
范围：研究数据接入、失败保护、数据透明度以及工作台交互；**不修改券商实盘下单逻辑**。

## 1. 本轮先解决的风险

原有 AKShare Adapter 在依赖缺失、网络异常或接口失败时静默生成 3 支固定股票、日线、分钟线和实时行情。日线按自然日生成，可能形成根本不存在的周末行情。默认路径没有数据来源标识，实际用户无法判断其是否来自交易所。

仅重写推荐 UI 会让这种错误变得更有迷惑性。因此决定先改变数据真实性契约。

## 2. 本轮实现

| 模块 | 变更 | 明确限制 |
|---|---|---|
| `services/data-ingest/data_ingest/market_data.py` | 默认 `MARKET_DATA_MODE=real`，AKShare 不可用、异常、返回空数据时报错；模拟行情仅允许显式 `mock` 且禁止生产环境 | 未覆盖真实分钟线，真实模式明确报错 |
| `services/data-ingest/data_ingest/data_sync.py` | 没有股票主表就不再兜底三个固定股票；OHLC、成交量、成交额做有界/有限校验；任一损坏日线会阻止整段窗口写入/推进游标；同步结果附加模式、来源与未验证标签 | 当前上游多个证券逐个提交，失败时可能部分成功；需后续任务原子化 |
| `apps/api/app/services/research_data_readiness.py` | 返回股票与日线覆盖、最近行情日期、同步模式、异常记录数、历史库风险与阻断原因 | 无逐条历史血缘，不宣称旧库数据已验证 |
| `/api/research/v2/data-readiness` | 只读 API，不触发模拟/真实交易 | `is_research_ready=false`，待可核实的 PIT 数据仓建成 |
| 研究工作台 | 首屏显示数据异常与来源提示，数据覆盖计数真实来自后端，旧版推荐清楚标明不可据此操作 | 暂不显示真实行业推荐、收益预测、已验证胜率 |
| 依赖与 CI | Pin AKShare 1.19.1，扩大 GitHub Actions 后端测试范围、保持 TypeScript 和 Next.js 构建验证 | 未执行浏览器 Playwright 视觉验收 |

## 3. 作为挑剔用户的第一次反向审查

### 缺陷 A（严重）：为什么上来先给我看漂亮的欢迎页，而不是告诉我数据是假的？

最初实现把数据质量卡放在主视觉后面，用户仍可能忽略。**第二次修改**：顶部加高对比异常提示，主按钮改成检查数据来源，模型试算降为次选路径。

### 缺陷 B（严重）：只要一条 K 线坏了，其他 K 线是否仍写进去并把同步游标推进？

初版只对“全错”样本阻止游标，存在缺陷。**第二次修改**：含任一损坏 bar 的整个证券日期窗口拒绝写入和推进；保留质量错误记录以供修复。

### 缺陷 C（严重）：已有数据库可能是旧版混合来源，它们是不是也能显示“可信”？

不能。由于原 schema 没有历史逐条来源或复权方式，新接口一律将其标为 `unverified_legacy_store`，禁止 V2 依据旧库数据输出实盘候选。即使最近一次同步注明 `real`，也不反向证明历史记录都真实。

### 缺陷 D（中）：真实模式还没装 AKShare，用户装好程序就看到错误

已经把 AKShare 1.19.1 加入 API 依赖，并使用 Docker 构建时安装。版本由 2026-09-30 PyPI 发行记录确认。**依赖存在并不代表网络/接口可用**；失败提示仍应准确可见。

## 4. 未完成事项：下一轮必须继续

1. 可隔离的 `market_data_batches` / `source_id` / `raw_hash` 数据血缘；阻断旧模拟数据进入真实评分。
2. 完整 PIT 基本面和行业归属时间序列，支持历史 ST、退市、送配、停牌、交易日与公告更正。
3. 先行业后个股的真实研究页，展示板块相对基准改善/恶化，以及企业基本面与风险事件；避免仅因上涨而入选。
4. 数据同步任务原子性、限流与重试策略、日志脱敏、数据源备选、价格复权口径。
5. OOS 模型基线对比、历史复盘和市场周期测试；没有可信 OOS 数据不声称策略产生 alpha。
6. 真实浏览器端、移动端截图比对和完整端到端回归。

## 5. 建议检查命令

```bash
cd apps/api
python -m pytest -q tests

cd ../web
npm ci
npx tsc --noEmit
npm run build
```

`GET /api/research/v2/data-readiness` 可以返回旧库存量信息，**不能作为新数据真实的证明**。环境文件里 `MARKET_DATA_MODE=real` 默认拒绝虚构兜底；只有在 `APP_ENV=test` 或其他非生产环境中明确设置 `MARKET_DATA_MODE=mock` 才会使用演示行情。
