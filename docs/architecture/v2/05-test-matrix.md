# QA SPEC-005：测试矩阵和发布门槛

## 自动化单测/API用例
- 同基准相同走势：相对 20/60 日为 0。
- 20 与 60 日严格对齐：数值基于正确历史切片，禁止未来函数。
- 修复与趋势算法在相同数据返回不同分数；输入重排不改变固定排序。
- 缺失/错序/重复日期、未来决策日、负/零/非有限价格、行业数超限、数据量超限 -> 422；不生成推荐。
- 来源只能 manual_unverified / synthetic_demo。模型版本、源等级、评估日期、哈希齐全。
- 没有 buy/sell/order/execute 等交易命令输出。隔离 Broker 和 LLM。
- 旧数据 readiness 仍为 False，旧流回归通过。

## CI
1. 后端 pytest 全集
2. TypeScript `npx tsc --noEmit`
3. `npm run build`
4. Next 服务 + Playwright 浏览器 smoke：空状态、演示加载、模型切换、风险标签、API 出错
5. 代码检视确认 domain 无 DB/网络/交易依赖

## 验证事实与未知
CI 没跑不能写“通过”；静态构建不代表视觉像素级验收；合成数据上算法输出准确也不证明真实超额收益。

## 上线门槛
只有 PIT、证券历史、成本、OOS 通过并由真实用户复核时，才可能接入实际候选输出。当前只能提供研究实验。
