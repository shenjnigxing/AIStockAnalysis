# SPEC-002：行业轮动模型实验设计

## 目标
对 1–6 个月 A 股中长线策略研究，首先比较行业而不是直接给股票生成“买入”评级。当前仅是研究假设。

## 强类型输入
- as_of：研究决策日（不晚于真实当前日期）。
- model：recovery / trend。
- benchmark：用户指定的基准 ID。
- benchmark_prices 与 sectors[].prices：共同的升序价格日期轴，每条数据含 date、close。
- 至少 61 个观测点；末日必须等于 as_of；行业数上限 12，观测点上限 260。
- 价格必须有限、正值；日期不重复、不未来、不乱序；基准必须严格同时间轴。

## 特征
设 S 为行业价格、B 为基准价格、t 为最后可见观测日（无未来数据）。
- r20 = 100 * ((S[t]/S[t-20])/(B[t]/B[t-20]) - 1)
- r60 = 100 * ((S[t]/S[t-60])/(B[t]/B[t-60]) - 1)
- prior20 = 100 * ((S[t-20]/S[t-40])/(B[t-20]/B[t-40]) - 1)
- acceleration = r20 - prior20（最近 20 日较上一个 20 日改善程度）
- drawdown60 = 100 * (1 - S[t]/max(S[t-60...t]))

## 不同假设，不混同
- recovery：过去 60 日偏弱、最近改善、加速度回升；对继续崩跌和反弹过热施加惩罚。
- trend：20/60 日相对收益偏强、持续性较好；追涨过热惩罚。
两个模型均用透明的阈值/权重归一化到 0–100 **研究强度**，不是概率或统计收益估计。返回 factor breakdown/risk flags。

## 复现与可信度
固定输入得到固定结果，排序按 score 降序、sector_id 升序打破平分。所有结果标 experimental、not_backtested、manual_unverified 或 synthetic_demo；绝不输出订单或所谓年化预测。

## 未来严格 OOS 基线
- 历史上市/退市、行业归属、ST/停牌与财报发布时间必须 PIT 化；财务更正只在更正公布后生效。
- 同期对照均权行业、标准相对动量、recovery、trend、LightGBM Ranker；宏观 regime 只能由历史可见信息估计。
- 20/60/120 日标签配套 purge/embargo 与 walk-forward；成本包含 A 股 T+1、涨跌停、佣金、印花税、滑点、容量约束、复权与分红。
- 记录样本外超额收益、RankIC、信息比率、回撤、换手、收益集中度、稳定性与不确定性。没有显著优势就不发布选股结果。

## 2026-10-21 实际集成结果后的反向模型修正（重要）

真实 FastAPI 端到端截图暴露：旧 recovery 权重过分奖励 60 日相对表现弱，即使近 20 日表现仍为负、改善加速度接近零，也可能打出接近 61 的研究强度；另一个合成行业短期已经大幅跑赢基准，仍可能占据修复型排序前列。此结果违背“弱势但开始改善、尽量避免追高”的模型目标。

因此在可解释规则层新增：
- 若 `acceleration_pp < 1.5` 或 `rel_20d_pct <= -3`，额外扣 24 分并标记“相对改善尚未确认”。
- 若 `rel_60d_pct > 10`，额外扣 15 分并标记“不属于低位修复阶段”。
- 原有持续下行、短期过热、60 日深度弱势与高回撤风险扣分保留。
- 原 UI 的“前期低关注”改为 **“前期相对弱势”**；仅凭价格数据不能证明市场关注度低（需要换手/交易笔数/持有人或舆情等独立数据）。
- 合成演示“修复行业”的价格路径改为前段弱势、后段改善，避免把已经累计明显上涨的行业误标成低位修复。

以上阈值仍属 **研究假设而非统计最优参数**。不得用此次合成测试的漂亮排序取代样本外验证；真实推荐升级仍被 PIT/OOS 阻断。
