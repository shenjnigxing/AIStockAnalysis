# ADR-007：A 股中长线个人投研算法选型与研究实验顺序

## 首先说明：未验证收益 = 不能称为“推荐算法有效”
你的研究任务是 1–6 个月的“先行业后个股”轮动与修复，而非涨停追逐。用户只需要每周一组可追溯的候选，能理解行业、企业、拥挤度、风险；不需要为了“AI 味”引入不稳定的语言模型当数学判断者。

## 候选方法/演进表

| 实验 | 输入与优点 | 主要局限 | 现阶段选型 |
|---|---|---|---|
| S0 行业基准相对强弱 | 同轴收盘序列、20/60日超额、加速度；可解释、无训练 | 没有基本面/复权/行业真实归属，价格不能等价于景气 | 本轮落地 2 套假设 |
| S1 行业景气与盈利修复 | 财报公告、盈利修订、行业产销、相对估值与拥挤度 | PIT 数据采购、行业口径与更新成本很高 | 首要下一阶段 |
| E0 个股健康过滤 + 风险模型 | 正现金流、ROE、财务质量、负债/估值分位；符合埋伏需求 | 财务数据有披露时滞及假阳性，不能只用盈利 >0 | PIT 完成后 |
| M0 透明加权因子/线性排序 | 稳定、可解释、少样本可拟合 | 无法学习非线性、行业条件差异 | 必须保留基准 |
| M1 LightGBM Ranker | 基于横截面超额收益排名、因子交互 | 时序过拟合、风格漂移、超参数据挖掘 | 当 PIT 与多个 OOS 阶段成熟后 |
| M2 CatBoost/XGBoost | 梯度提升替代基线，检验稳健性 | 不应只挑历史回测最好模型 | 与 M1 同窗对照 |
| M3 动态 regime/贝叶斯模型平均 | 权重随市场环境切换，但必须只用时点可见输入 | regime 识别错误导致切换追涨杀跌 | OOS 优胜后再考虑 |
| RL / 深度时序模型 | 非线性时序与策略动作研究 | 数据样本复杂、资金成本高、失败模式不透明 | R&D，不进入主产品 |
| LLM / 多 Agent | 检索公告、提炼多空论证、给出引用与反证 | 幻觉、版本漂移、事后解释 | 证据助手，不修改量化得分、不发订单 |

## 真正的模型注册治理
- 每个模型版本必须绑定：`dataset_release`、`universe_version`、`features_hash`、`label_horizon`、`training_range`、`oos_range`、`cost_model`。
- 固定训练/测试切分及 pre-registration；严格 purge 标签重叠区间与 embargo，避免数据挖掘。
- 严禁用同一期测试结果反复调权重再宣称样本外。
- 每季度报告模型退化：IC、ICIR、RankIC、最大回撤、换手、实盘可成交率、收益集中度、稳健性区间。
- 由 User Advocate 给出可用性缺陷、Quant 提交结果、Data Engineer 验 PIT、Risk 验成本；任何一项不足只读观察。
- 研究页面尽可能呈现“样本外是否有效/何时失效”，分数色条属于诊断工具，不是推荐置信度。

## 为什么先做 S0
- 能精确实现、用合成数据验证公式和时间边界，不引入未来函数。
- 能揭露 API 的时点、排序、数据来源契约问题。
- 不能证明真实收益，因此用实验名称和 demo 阻断，不伪装成智能荐股完成版。
