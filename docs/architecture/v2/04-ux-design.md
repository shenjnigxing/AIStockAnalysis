# UI SPEC-004：个人研究工作台与行业实验

## 信息架构
研究工作台 / 行业轮动 / 个股研究（未来） / 因子实验 / 回测 / 数据质量。行业轮动作为独立左导航入口，先行业后个股。

## 两种场景
**默认空状态**：用户首次进入只看见状态“无真实可验证数据”，支持选择“加载合成演示”，不会自动把虚构排行放在眼前。

**显式演示后**：持续显示大字 DEMO、基准、数据日期、模型类型；展示行业表格（行业、相对20日、相对60日、变化、回撤、研究强度），选择模型可比较同数据下的假设排序；给出风险标签及因子分解。

## 设计语言
- 深色侧导航，工作区浅色、细边框、高信息密度但不拥挤；原子化模块。
- 数字表格使用 tabular-nums；关键限制靠文字+图标而非颜色。
- 主要 CTA 仅一个（演示/运行）；异常时禁止出现虚构成功态。
- 1024px / 375px 适配；窄屏行业表横向滚动，不藏住操作按钮。
- 按钮键盘可达、visible focus、error aria-live、form 有 label；不强制 hover 才能查看数据。
- 结果不使用“胜率”或“预计涨幅”，也不做“AI 推荐”冒充科研。

## 用户任务验收
1. 没有数据时不会看到真实市场排行。
2. 点击合成示例，结果醒目标注 DEMO，日期及基准可见。
3. 一键在两模型切换；输入数据不变，评分解释改变。
4. 点入某行业，看到子因子、风险、原始相对收益而不只是一个总分。
5. 输入时点/序列不合格时能看到直接错误解释，不出现半正确排行。
6. 阅读屏、手机和键盘都能完整完成操作。

## 设计批判闭环
第一版发现：单股 JSON 表单不是日常工作台；改引导表单后仍需自己输入13个数字。此次独立行业实验仍是手工数据切片，不把它伪装成自动扫描；下一步须以真实 PIT 数据集驱动“一键生成行业研究池”。
