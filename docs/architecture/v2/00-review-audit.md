# V2 独立技术/产品/UX 审计（2026-10-21）

审计对象：现有 V2 分支代码、旧系统推荐流水线、自动化检查记录。不是线下访谈，也没有假称已运行独立代理。

## 审计结论
| 级别 | 缺陷 | 证据 | 设计决策 |
|---|---|---|---|
| P0 | 旧行情库没有逐行来源，可能混入模拟行情 | 旧 Adapter 曾在异常时合成股票/行情；旧 DailyBar 无 source_id | 维持真实推荐阻断，数据仓迁移独立进行 |
| P0 | 原推荐分数可被 LLM adjustment 修改，动作建议含 execute | recommendation_core/recommendation.py | V2 研究域不得调用 LLM 调整得分或真实交易路径 |
| P1 | V2 行业分主要靠手工字段，不是独立计算的轮动模型 | research_v2.py 从 sector_excess_20d_pct 等直接评分 | 建独立行业收益序列及双模型研究实验 |
| P1 | API 接收无上限内部字段和结构 | list[dict] | 新路由用 Pydantic 数量、长度、时间、数值边界 |
| P1 | UI 把演示和研究入口混排，缺行业选项与可解释分项 | research/page.tsx | 新建行业实验台，手动加载合成演示、持续 DEMO 标签 |
| P1 | 固定因子权重未样本外校验 | 所有 V2 评分仅研究假设 | score 不等于概率，标 not_backtested |
| P2 | 多微服务复杂度过高不适合单人维护 | 现有应用及 services 包 | 模块化单体/纯函数核优于盲目拆服务 |
| P2 | 仅构建/单元测试不能证明 UI 交互质量 | CI 缺实际交互记录 | 加浏览器 smoke，保留视觉验收缺口 |

## 架构评级
旧界面视觉层级有进步，但只是 Research Preview；数据契约 P0 未过，算法没有任何 OOS 证据。高级架构不等于 Agent、神经网络或技术名词堆叠；目标是可复现、时间正确、解释清楚、成本可控。

## 本轮范围
仅做独立的行业轮动研究切片，输入为显式用户提供的同一交易日历价格序列；对比早期修复（recovery）与趋势延续（trend）。它不能被宣传为真实板块排名，不能连到券商执行。

## 下一轮阻断
历史 PIT 成分、复权、财务披露时点、真实基准、退市证券、slippage、OOS/回测验证尚未实施；任何一期的测试都不得绕开。
